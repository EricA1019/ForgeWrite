# Generated Code Output

This directory contains code generated by ForgerWrite + OmniCoder for manual
testing and review. Each subdirectory is a self-contained Rust project.

## Running a demo

```bash
cd _output/counting_demo
cargo run
```

## Adding a new demo

```bash
cd _output
cargo init my_new_demo
cd my_new_demo
FORGERWRITE_ROOT=$(pwd) uv run --directory ../.. forgerwrite init
# Edit .forgerwrite/forgerwrite.toml to configure the model endpoint
# Run: python3 ../experiment.py (or your experiment script)
```

## Notes

- `_output/` is in `.gitignore` — code here is not committed to the repo
- Each demo project has its own `.forgerwrite/` config
